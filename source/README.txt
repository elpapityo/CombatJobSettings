Combat Job Settings V0.1.0
==========================

概要
----
BossMod / BossMod Reborn / Rotation Solver Reborn (RSR) / Wrath Combo の
主要な戦闘設定を1つの画面で確認・変更するDalamudプラグインです。

各プラグインを個別に開かなくても現在値を確認でき、設定を
JOB別・ロール別・名前付きプリセットとして保存して切り替えられます。

主な機能
--------
- BossMod AI ON/OFF の現在値取得・変更
- BossMod Reborn AI / Follow target / 距離設定の現在値取得・変更
- RSR 停止 / 自動 / 手動、Engage settings、敵優先条件の現在値取得・変更
- Wrath Auto Rotation、攻撃設定・回復設定の現在値取得・変更
- JOB別設定の保存・適用
- ロール別設定の保存・適用
- 自由な名前を付けるプリセット保存・適用・上書き
- 保存済みデフォルトへの復元
- JOB変更時の自動適用
- CJS Mini（簡易操作ウィンドウ）
- 各本家プラグイン設定画面を開くショートカット

設定の優先順位
--------------
JOB変更時の自動適用は次の順で設定を探します。

  1. 現在JOBの保存設定
  2. 現在ロールの保存設定
  3. 保存済みデフォルト

JOB・ロール設定が無い場合に、直前のJOBの設定をそのまま引き継ぐことはありません。
保存済みデフォルトへ戻します。

初回に必ず行うこと
------------------
1. 普段使っている各戦闘プラグインの設定を整えます。
2. CJSの「設定」タブを開きます。
3. 「現在の実設定をデフォルトとして保存」を実行します。
4. その後にJOB別・ロール別・名前付き設定を作成してください。

デフォルトは復元基準です。デフォルト未保存の状態ではJOB変更時の自動適用は有効にできません。

保存対象
--------
CJSが管理対象としている項目だけを保存・適用します。
CJS画面に存在しない本家プラグイン側の設定は変更しません。

対応プラグインが未導入・未ロードの場合
----------------------------------
そのプラグイン分だけ現在値取得・変更・設定画面起動をスキップします。
CJS全体や、他の導入済みプラグインの動作は継続します。

CJS Mini
--------
必要な項目だけを表示できる簡易操作ウィンドウです。
表示項目はCJSの設定タブから選べます。

標準表示候補:
- 現在JOB / ロール
- BM AI
- BMR AI
- RSR 停止 / 自動 / 手動
- Wrath Auto Rotation
- 保存済みJOB / ロール / デフォルト / 名前付きプリセットの適用
- CJS各タブを開くボタン
- 本家プラグインを開くボタン

Miniは本文背景とタイトルバーの濃さを別々に調整できます。

コマンド
--------
  /cjs

CJS本体を開きます。ゲーム起動時に本体・Miniは自動表示しません。

設定ファイル
------------
保存場所はCJSの「設定」タブで確認・変更できます。
標準ではプラグイン設定ディレクトリ配下を使用します。

  Settings.json         CJS本体設定
  DefaultSettings.json  復元用デフォルト
  JobProfiles.json      JOB別設定
  RoleProfiles.json     ロール別設定
  NamedProfiles.json    名前付きプリセット

JSON内には、直接開いた時に判別しやすい日本語説明も保存されます。

ビルド
------
必要環境:
- Dalamud API 15
- .NET 10 SDK

ZIPを展開し、build.bat を実行してください。
ビルド成功後、次の場所に配布用ファイルが作成されます。

  release\CombatJobSettings\

生成された CombatJobSettings フォルダをDalamudのローカルプラグインとして使用できます。

注意
----
- 連携先プラグインの更新により、設定名や外部操作方法が変更された場合は一部機能が利用できなくなることがあります。
- 本プラグインは連携先プラグイン本体の全設定をバックアップするものではありません。
- 設定変更前にデフォルトを保存しておくことを推奨します。
